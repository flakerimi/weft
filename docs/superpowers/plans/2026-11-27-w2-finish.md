## Review Focus

1. **`enum` literal types in `api.ts`:** A string field or parameter with `warp:"enum=draft|live"` becomes `'draft' | 'live'` (`'draft' | 'live' | null` on `*string`); a numeric field or parameter with `warp:"enum=1|2|3"` becomes `1 | 2 | 3` (`1 | 2 | 3 | null` on `*int`); values containing `'` or `\` are escaped with `quote`; `schema` keeps `kind: 'string'` or `kind: 'number'`.
2. **Duplicate or invalid `enum` rules in `warp`:** Two `enum` rules on one field fail registration with `<Type>.<Field> has the rule "enum" more than once; list every value in one enum=a|b.`; a non-numeric choice on a number field fails registration with `<Type>.<Field> has "enum=1|x"; write numbers separated by | after enum=.`.
3. **Typed `useParams(pattern)`:** `useParams('/products/:id')` returns `{ id: string }`; accessing `.other` or passing an unknown route pattern fails `vue-tsc`; `useParams()` with no argument returns `Record<string, string>`; calling `useParams('/other/:id')` at run time on a page whose `data-weft-route` is `/products/:id` returns `{}` and warns once in development (never in production) naming both patterns.
