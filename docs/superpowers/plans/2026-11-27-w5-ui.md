# W5 UI Blocks (`Table` Debounce, `EntityDialog`, `DataTable`, Shop Conversion) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the UI side of Warp phase W5 for `0.1.0` (owned by Argon): add debounced server-side search to `Table` (`useTableData`), build `EntityDialog` and `DataTable` in `packages/ui/src/data/` with docs, examples and catalogue entries, and convert `examples/shop` to use `DataTable`.

**Architecture:** `packages/ui/src/data/useTableData.ts` debounces non-empty `search` changes by `searchDebounce` ms (default `250`) while cancelling superseded requests; `packages/ui/src/data/entity.ts` holds the shared types, value diffing (`changes`), field humanization and `ApiError` classification (`entityProblem`); `packages/ui/src/data/EntityDialog.vue` wraps `Dialog` and `Form` to auto-render controls from a generated `schema` (or render custom slot controls), diff changes on `PATCH`, and map field/top-level errors; `packages/ui/src/data/DataTable.vue` composes `Table`, `EntityDialog` and `ConfirmDialog` over a `data.Resource` client object (`{ list, create, update, remove }`); and `examples/shop/web/components/ProductsTable.vue` uses `DataTable`.

**Tech Stack:** Vue `3.6.0-rc.16` (`<script setup vapor lang="ts">` only), TypeScript, Vite, Vitest in `packages/ui/` and `examples/shop/`.

**Spec:** `docs/superpowers/specs/2026-11-27-w5-design.md`.

## Review Focus

1. **`Table` debounced search:** Typing several characters in `search` within `searchDebounce` ms fires `fetch` once with the final query, not on every keystroke; an in-flight request from before a keystroke is ignored when it resolves or rejects later; clearing `search` to `''` or changing `sort`, `filters` or `page` cancels any pending timer and asks `fetch` immediately.
2. **`EntityDialog` create, edit, diff and error mapping:** Opening in create mode initializes defaults from `schema` and `defaults`; opening in edit mode copies the record; saving an edit with no changed fields closes without calling `update`; saving an edit with changed fields sends only the changed keys to `update(id, changed)`; an `ApiError` with known `fields` sets field errors on `Form`, an unknown field key in `e.fields` or a top-level message renders in the top `Alert`, `code === 'network'` shows the unreachable sentence, and a non-`ApiError` logs to `console.error` and shows the generic page-failed sentence; reopening clears all previous errors; `enum` with `<= 4` choices renders `RadioGroup` on `regular`/`wide` and `Select` on `narrow`.
3. **`DataTable` resource wiring and actions:** Passing `:resource="api.products"` wires `list`, `create`, `update` and `remove` with no adapter; toolbar shows debounced search, filter controls from `filterDefs`, and `"New <name>"` when `create` is present; row actions column appears only when `update` or `remove` is present; Delete opens `ConfirmDialog`, displays any `ApiError` inside the dialog while staying open, and refreshes the table on success.
4. **`examples/shop` conversion:** `examples/shop/web/components/ProductsTable.vue` uses `DataTable`, and `TestShop`, `TestShopRenamedFieldBreaksTypes` and `TestShopInBrowser` in `cmd/weft` all pass.
