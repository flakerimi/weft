# Warp Core (W1) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** An app made by `weft create` is a `warp.App` with a list of modules, whose routes are typed Go functions that get a validated input struct and answer in one JSON shape, and all Go code is imported as `github.com/flakerimi/weft/warp`.

**Architecture:** A new package `warp/` holds the core. The three files that are `weft.Serve` today move into it unchanged in behaviour. Around them: a `Config` read from `.env` and the environment, an `App` that owns one `http.ServeMux` under `/api`, modules registered in the order listed, generic route functions that bind and validate an input struct by reflection, and one error type that every answer goes through. The template's `api/` becomes `app/hello/`, a module, listed in `app/modules.go`.

**Tech Stack:** Go 1.26, standard library only (`net/http`, `reflect`, `encoding/json`, `log/slog`, `os/signal`).

**Spec:** `docs/superpowers/specs/2026-11-23-warp-design.md`, phase W1, with *The core*, *Wire format* (the error shape and statuses) and *Validation*.

## Calls made by Claude (Task 8 writes them into the spec)

1. **No `weft.Serve` left behind.** The root package keeps only `Version`. Nothing is published, so a forwarding function would only be a second name.
2. **`warp.Serve` is the handler; `(*App).Serve` listens.** `warp.Serve(dist, api, opts...)` is today's function. `app.Serve(dist)` builds it over the app's own API, listens, and stops cleanly on SIGINT or SIGTERM.
3. **Mistakes in registration are collected, not panicked.** `app.Use`, `app.Handle` and `warp.Get` return nothing; `app.Err()` and `app.Serve` report every mistake, one sentence each. The spec's `warp.Get(app, ...)` has no error to check, and a panic at import time has no place to name the file.
4. **Route paths are written without `/api`**; the app adds it. `warp.Get(app, "/products/{id}", show)` answers at `/api/products/{id}`.
5. **Every exported field of an input struct has a `json`, `query` or `path` tag.** A field without one is a registration mistake, so no field gets Go's default name (`Name`) in a snake_case API.
6. **An unknown field in a JSON body is a 400.** A misspelt field that is silently dropped is how an update loses data.
7. **`POST` answers 201** unless the route says `warp.Status(200)`. An output of `warp.None` answers 204.
8. **A path value that does not convert is a 404**, not a 400: `/api/products/abc` names nothing.
9. **`unique` is parsed here and enforced in W3**, by `warp/data`, which is the first thing that can look.
10. **`weft dev` sets `HOST=127.0.0.1`, and `warp` watches for the dev parent**, so `dist_dev.go` keeps no logic. The file stays, with its comment, because the `dev` tag still needs explaining.
11. **Out of scope:** `filter[...]` and list queries (W3), present-or-absent PATCH fields (W3), `auth.Can` and a route's permission (W4), `warp/describe` (W2). `Route` is shaped so each can add a field.

## Global Constraints

- **Inherited:** every rule in `AGENTS.md`.
- **Standard library only**, in `warp/` and in the template's Go.
- **Nothing registers itself from an `init` function.** Modules are listed in `app/modules.go`.
- **Every error is one sentence** that names the thing and says what to do: at registration, at startup and in API answers. An API answer never carries a Go error's text unless the handler returned a `*warp.Error`.
- **One error shape:** `{"error":{"code":"…","message":"…","fields":{…}}}`, with `fields` left out when empty, `Content-Type: application/json`.
- **JSON names are snake_case.**
- **Files move with `git mv`.** Nothing is deleted; if a step seems to need a deletion, stop and ask the owner.
- **The release's `-X github.com/flakerimi/weft.Version=` flag keeps working**: `version.go` stays in the root package.
- **Docs describe the code as it is**: Task 8 moves what this plan delivers out of `coming-next.md`.
- **Work in a worktree** at `.worktrees/warp-core`, branch `warp-core`. Run the full suite in `AGENTS.md` before each commit; no `Co-Authored-By` line.

## Review Focus

1. **A body that is not what the route expects.** Empty, not JSON, JSON followed by more text, an unknown field, a string where a number goes, 2 MB: each is a 4xx in the error shape and the handler is never called. (Task 6.)
2. **A handler that panics or returns a plain error.** The answer is a 500 in the error shape with none of the error's text, the log has it, and the next request is served. (Task 4.)
3. **A mistake made while registering.** A `path` tag with no wildcard, a wildcard with no field, the same route twice, an unknown rule, `email` on an `int`, a field with no tag: each is one sentence from `app.Err()` naming the struct and field, before any request. (Tasks 5, 6.)
4. **An optional field with rules.** An empty optional `email` passes; a nil pointer fails only `required`; `min=1` on a number that is 0 and not required passes. (Task 5.)
5. **Stopping.** A request in flight when SIGTERM arrives finishes; modules stop in reverse; when the third module fails to start, the first two are stopped; a taken port is one sentence. (Task 4.)

### Task 3: Configuration from `.env`

**Files:**
- Create: `warp/env.go`, `warp/env_test.go`

**Interfaces:**
- Produces:
  ```go
  type Config struct {
      Host         string // HOST; empty is every interface
      Port         string // PORT; default "8080"
      MaxBodyBytes int64  // MAX_BODY_MB × 1 MiB; default 1 MiB
      // unexported: vars map[string]string, err error
  }
  func FromEnv() Config                          // ./.env if it exists, then the environment, which wins
  func ConfigFrom(vars map[string]string) Config // the same, from a map; for tests and for apps that configure themselves
  func (c Config) Get(key string) string         // "" when unset
  func (c Config) On(key string) bool            // on, true, 1, yes, in any case
  func (c Config) Err() error
  ```
  A zero `Config` works: port 8080, 1 MiB.
- The `.env` grammar: one `KEY=value` per line; blank lines and lines starting `#` are skipped; a leading `export ` is dropped; a key matches `[A-Za-z_][A-Za-z0-9_]*`; a value in single or double quotes is what is between them, with no escapes; an unquoted value is trimmed and ends at ` #`. There is no `${}` expansion.
- Errors (through `Err`, and `New` carries them into `app.Err`):
  - `.env line 3 is "FOO"; write it as KEY=value, or start it with # to make it a comment.`
  - `PORT is "abc"; set it to a number from 1 to 65535 in .env or the environment.`
  - `MAX_BODY_MB is "big"; set it to a whole number of megabytes, 1 or more, in .env or the environment.`

### Task 4: The app, its modules and its life

**Files:**
- Create: `warp/app.go`, `warp/run.go`, `warp/app_test.go`, `warp/run_test.go`

**Interfaces:**
- Consumes: `Config` (Task 3); `WriteError`, `NotFound` (Task 2); `Serve`, `Option` (Task 1).
- Produces:
  ```go
  type Module interface { Name() string; Register(app *App) error }
  type Migrator interface { Migrate(ctx context.Context) error }
  type Starter  interface { Start(ctx context.Context) error }
  type Stopper  interface { Stop(ctx context.Context) error }

  type Route struct { Method, Path string; In, Out reflect.Type; Status int } // Path has /api; In and Out are nil for Handle
  type RouteOption func(*routeConfig)
  func With(mw func(http.Handler) http.Handler) RouteOption // around this route, first given outermost
  func Status(code int) RouteOption

  func New(cfg Config) *App
  func (a *App) Config() Config
  func (a *App) Use(modules ...Module)
  func (a *App) Handle(pattern string, h http.Handler, opts ...RouteOption) // "GET /export.csv": a method, a space, a path without /api
  func (a *App) Wrap(mw func(http.Handler) http.Handler)                    // around every API request, first given outermost
  func (a *App) Err() error                                                 // every mistake so far, joined; nil when none
  func (a *App) Routes() []Route                                            // in the order registered
  func (a *App) Handler() http.Handler                                      // the API alone, at /api/...
  func (a *App) Serve(dist fs.FS, opts ...Option) error
  func (a *App) Run(ctx context.Context, ln net.Listener, dist fs.FS, opts ...Option) error
  ```
  Unexported, for Task 6: `func (a *App) route(method, path string, in, out reflect.Type, h http.Handler, opts []RouteOption)` and `func (a *App) fail(format string, args ...any)`.
- Behaviour:
  - `Use` calls each module's `Register` at once, in order. Mistakes, each prefixed `warp: `: `two modules are named "auth"; give one another name.`, `module "auth" could not register: <its error>`, `Use was called after the app started serving; list every module before Serve.`
  - `Handle` and `route`: the path must start with `/` and must not start with `/api/` (`route "/api/x" already gets /api in front; write it as "/x".`). A pattern the mux refuses (a conflict, a bad wildcard) is recovered into `route "GET /x" cannot be registered: <the mux's reason>`.
  - `Handler`: recovers a panic into `WriteError` with the panic as a plain error; a path no route matches is 404 `not_found`, `Nothing is at /api/x.`; a path that matches with another method is 405 `method_not_allowed`, `/api/hello does not take POST; use GET.`, with the `Allow` header. Find these with `mux.Handler(r)`: an empty pattern means the mux's own 404 or 405, which is run into a recorder to read its status and `Allow`.
  - `Run`: returns `Err()` if not nil, before anything else. Then `Migrate` on every `Migrator` in order, `Start` on every `Starter` in order, serves on `ln` (`warp.Serve(dist, a.Handler(), opts...)`, or the API alone when `dist` is nil), and when `ctx` ends shuts the server down with a 10 s limit and calls `Stop` in reverse order. A failed step is `warp: module "jobs" could not start: <err>` (`migrate`, `stop` likewise), and the modules already started are stopped. `Run` returns nil after a clean stop.
  - `Serve`: listens on `Host:Port` (`warp: port 8080 is taken; stop what uses it or set PORT in .env.` when it is), logs `listening on http://localhost:8080`, and calls `Run` with a context that SIGINT and SIGTERM end. When `WEFT_DEV_PARENT=1` it logs nothing and the context also ends when standard input closes.

### Task 5: Validation

**Files:**
- Create: `warp/validate.go`, `warp/validate_test.go`

**Interfaces:**
- Produces:
  ```go
  func Validate(v any) error                   // nil, or Invalid(fields); v is a struct or a pointer to one
  func checkRules(t reflect.Type) []string     // every mistake in t's warp tags, as sentences; Task 6 calls it at registration
  ```
- Rules, in the `warp` tag, comma-separated:

  | Rule | Applies to | Fails when | Message |
  | --- | --- | --- | --- |
  | `required` | anything | the value is zero, a nil pointer, or a string that is empty once trimmed | `This is required.` |
  | `email` | string | `net/mail.ParseAddress` fails, or the address has a display name | `Enter an email address.` |
  | `url` | string | it does not parse as an absolute `http` or `https` URL with a host | `Enter a web address that starts with http:// or https://.` |
  | `min=N` | string (characters), number (value), slice (length) | below N | `Use at least N characters.` / `Enter N or more.` / `Choose at least N.` |
  | `max=N` | the same | above N | `Use at most N characters.` / `Enter N or less.` / `Choose at most N.` |
  | `enum=a\|b` | string | not one of them | `Choose one of: a, b.` |
  | `unique` | string, number | never, in W1 | (W3) |

  Every rule but `required` passes a zero value and a nil pointer, so an optional field may be empty. A pointer's rules apply to what it points at. Only the first failing rule of a field is reported, in tag order. A field's key is its `json`, `query` or `path` name; a struct inside is `address.city`, a slice of structs `lines.0.sku`. N in a message is written as the tag has it.
- `checkRules` sentences: `Product.Price has the rule "emial", which warp does not know; use required, email, url, min=, max=, enum= or unique.`, `Product.Price has the rule "email", which is for text; remove it or make the field a string.`, `Product.Name has "min=abc"; write a number after min=.`, `Product.Status has "enum=" with nothing to choose from; write enum=a|b.`

### Task 6: Typed routes

**Files:**
- Create: `warp/bind.go`, `warp/route.go`, `warp/bind_test.go`, `warp/route_test.go`

**Interfaces:**
- Consumes: `(*App).route`, `(*App).fail`, `RouteOption` (Task 4); `Validate`, `checkRules` (Task 5); `WriteError`, `WriteJSON`, `BadRequest`, `NotFound` (Task 2); `Config.MaxBodyBytes` (Task 3).
- Produces:
  ```go
  type None struct{} // as In: nothing is read; as Out: 204 and no body

  func Get[In, Out any](app *App, path string, fn func(context.Context, In) (Out, error), opts ...RouteOption)
  func Post[In, Out any](…)    // 201
  func Put[In, Out any](…)
  func Patch[In, Out any](…)
  func Delete[In, Out any](…)

  func Request(ctx context.Context) *http.Request        // the request a typed handler is answering
  func ResponseHeader(ctx context.Context) http.Header   // headers to send with its answer, such as Set-Cookie
  ```
- Binding, in this order: the JSON body into the fields tagged `json` (only for `POST`, `PUT` and `PATCH`; an empty body is `{}`); then every `query` field from the query; then every `path` field from the path. `query` and `path` fields are never set from the body. They may be `string`, `bool`, any int, uint or float kind, and, for `query`, a `[]string` of the repeated values. Then `Validate`, then `fn`.
- Answers when binding fails, all through `WriteError`, the handler never called:

  | Condition | Status, code | Message, fields |
  | --- | --- | --- |
  | Body larger than `MaxBodyBytes` | 413 `too_large` | `The body is larger than 1 MB.` (the limit, in MB) |
  | Body is not JSON, or has text after the value | 400 `bad_request` | `The body is not valid JSON.` |
  | Body has a field the struct lacks | 400 `bad_request` | `The body has the field "nme", which this route does not take.` |
  | A body field has the wrong type | 400 `bad_request` | `1 field has the wrong type.`, `fields`: `Send text.`, `Send a number.`, `Send true or false.`, or `Send a list.` |
  | A query value does not convert | 400 `bad_request` | `1 field has the wrong type.`, `fields`: `Send a whole number.`, `Send a number.` or `Send true or false.` |
  | A path value does not convert | 404 `not_found` | `Nothing is at /api/products/abc.` |
  | A rule fails | 422 `validation` | as Task 5 |
- Registration mistakes, through `app.fail`, each prefixed `warp: `, with the route as `GET /products/{id}`:
