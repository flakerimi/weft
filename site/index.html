weft

One UI system for Go and Vue apps.
Vapor-first components that know whether they're under a finger or a mouse, on a landing page or in an app — shipped inside a single Go binary.

curl -fsSL https://weft.base.al/install | sh

Already installed? weft update moves you to the newest release; weft update --check only looks.

  • Yours, all the way down. Every component, API and style is Weft's.
  • Adaptive by default. Written once; sized and shaped for touch or pointer, landing or app.
  • Go-first. One binary serves your API and embeds your Vue app.
  • Built for agents. Big building blocks and one way to do each thing.

Installs to ~/.local/bin. Set WEFT_BIN_DIR to change it, WEFT_VERSION to pin one.
